HOW TO SUBMIT

Submit in four steps

1️⃣
Predict
One 0/1 prediction for every PassengerId in test.csv.
2️⃣
Save
A CSV named predictions.csv with exactly two columns.
3️⃣
Zip
Put that one file in a .zip, e.g. submission.zip.
4️⃣
Upload
My Submissions → choose the zip → submit. Refresh after a minute.
COPY, PASTE, SUBMIT

The code

import zipfile
import pandas as pd

sub = pd.DataFrame({'PassengerId': test['PassengerId'],
                    'Survived':    model.predict(X_test)})
sub.to_csv('predictions.csv', index=False)

with zipfile.ZipFile('submission.zip', 'w') as z:
    z.write('predictions.csv')

TROUBLESHOOTING
Submission failed? Open its log. The scorer tells you exactly what is wrong: a missing column, a missing passenger, or probabilities (0.73) instead of 0/1. Use model.predict(), not predict_proba().
